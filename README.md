7# 🎬 Movie Object App

A dynamic movie details application built using pure JavaScript DOM manipulation.

This project demonstrates how JavaScript can:
- Create HTML elements dynamically
- Style elements without CSS
- Handle button click events
- Display object properties on a webpage
- Work with arrays inside objects

---

## 🚀 Features

✅ Dynamic element creation using JavaScript  
✅ Movie object with multiple properties  
✅ Actors stored inside an array  
✅ Interactive button functionality  
✅ Styling done completely with JavaScript  
✅ Responsive centered layout  

---

## 🛠 Technologies Used

- HTML5
- JavaScript (DOM Manipulation)

---

## 📚 Concepts Practiced

- Objects
- Arrays
- DOM Manipulation
- createElement()
- innerText
- innerHTML
- appendChild()
- Button Events
- JavaScript Styling

---

## 🎥 Movie Details Included

- Movie Name
- Genre
- Rating
- Actors
- Release Date
